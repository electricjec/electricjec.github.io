coshē PocketReader

A pocket-sized dedicated reader built around offline storage, physical controls, and a custom firmware experience.

ESP32-S3C++Embedded UImicroSDWi-Fi

Overview

A reading device built around focus rather than general-purpose computing.

coshē is a handheld e-reader built around an ESP32-S3, a 2.8-inch display, microSD storage, physical navigation buttons, and a rechargeable battery system.

The project grew from basic hardware bring-up into a full reading workflow: library browsing, book import, pagination, progress tracking, themes, and a local Wi-Fi uploader.

The goal is a self-contained device that can receive books from a browser and then operate offline as a dedicated reader.

What I learned

The interface is part of the hardware.

coshē reinforced that embedded product design is not only about connecting modules. Firmware architecture, storage behavior, interaction, typography, power, and enclosure constraints all shape how the hardware feels.

The strongest improvements came from treating the reader as one product rather than a collection of separate embedded features.

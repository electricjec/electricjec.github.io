Solar Cleaning Robot

A mobile cleaning robot combining sweeping, mopping, water dispensing, solar-assisted charging, and local browser control.

ArduinoESP32Motor ControlSolar ChargingWater Dispensing

Overview

Cleaning functions, motion, power, and wireless control on one platform.

The Solar Cleaning Robot brings multiple subsystems onto one mobile platform: drive motors, a sweeping mechanism, a mopping mechanism, water dispensing, portable power, and solar-assisted charging.

An Arduino handles the robot functions while an ESP32 provides a local web interface for simple wireless control.

The project is primarily an integration challenge: the mechanical cleaning functions, electrical loads, water system, power architecture, and controls all need to work together on a moving chassis.

What I learned

Robotics is systems integration in motion.

The project emphasized that a robot can only be as reliable as the interaction between its mechanical, electrical, power, and control subsystems.

It also showed the value of keeping the user-facing control layer simple even when the hardware underneath is doing several things at once.

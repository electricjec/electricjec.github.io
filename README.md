# Jaron Canceran Portfolio

This package is built directly around the existing website files and assets from the uploaded archive.

## Included
- Existing homepage design and current images
- Clickable project cards
- Full case-study layouts for all five projects
- Shared responsive project-page stylesheet
- Graceful labeled placeholders for photos that have not been supplied yet
- Updated sitemap for all project pages
- Image shot list showing what is actually worth photographing

## Local preview
From this folder run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## Adding photos later
Place new files in `assets/images/`. The placeholders intentionally do not reference missing files, so the website will not show broken-image icons while those photos are still absent.
